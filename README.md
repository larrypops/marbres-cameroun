# CAMEROUN MARBRE DECOR - Next.js

Ce projet a été migré vers **Next.js App Router**.

## Pré-requis

- Node.js 20+
- npm

## Lancer en local

1. Installer les dépendances :
   `npm install`
2. Démarrer le serveur de développement :
   `npm run dev`
3. Ouvrir :
   `http://localhost:3000`

## Build de production

1. Générer le build :
   `npm run build`
2. Démarrer en mode production :
   `npm run start`

## Images locales

Les visuels utilisés par le site sont servis depuis `public/images` et référencés avec des chemins absolus comme :

- `/images/marbre-01.jpg`
- `/images/marbre-02.jpg`
- `/images/marbre-03.jpg`

Les fichiers sources sont aussi conservés dans le dossier `images/`.
